# Dhalal Scents Website

A responsive luxury fragrance and skincare storefront concept built with **HTML, CSS and JavaScript**.

## Pages / sections
- Home
- Shop (Perfumes, Skincare, Deodorants)
- About
- Contact

## Features
- Responsive desktop and mobile layout
- Mobile navigation
- Product category filters
- Product search
- Favourite buttons
- Contact form demo interaction

## Run locally
Open `index.html` in your browser. No build tools are required.

## Before publishing
- Replace sample product names, prices and descriptions with your real catalogue.
- Replace the demo email address with your business email.
- The contact form is front-end only; connect it to a backend or form service to receive messages.
- Add a secure checkout and order-management backend if you plan to sell online.
- Product visuals are CSS illustrations and the hero/about photos load from Unsplash, so internet access is needed for those photos and Google Fonts.
